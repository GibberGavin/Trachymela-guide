Key to the species of Trachymela.

Description

This Lucid interactive key allows you to identify the species of the eucalypt leaf beetle genus, Trachymela, as well as several other species that are often mistaken for them. To use this key for any specimen, it is first necessary to make sure that the species you are identifying is a species of Trachymela. The paper by Reid (2006) has a key to the Australian Chrysomelinae that will help in that task. If using any colour character provided in the key, the specimen should be fully hardened (not tenereal).
